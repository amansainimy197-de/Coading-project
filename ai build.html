FAQ

Questions, answered

Is my data private?

Profile data is stored only in your browser. Prompts are sent to the AI backend only when a backend is connected; in demo mode nothing leaves your device.

What is demo mode?

If no AI backend is reachable, SmartMind uses a built-in offline engine that produces structured template responses so you can try the interface.

Can I connect a real AI API?

Yes. Expose a POST /api/generate endpoint that returns { "text": "..." } and a GET /api/status endpoint that returns { "configured": true }. Keep your API key on the server.

Does it work on mobile?

Yes — the layout is fully responsive and keyboard accessible.
